# Sora

Font: Sora, Jonathan Barnbrook e Julián Moncada. Copyright 2019 The Sora Project Authors.

- `Sora-Variable.ttf`: font variabile originale, asse `wght` 100–800.
- `Sora-Variable.woff2`: conversione WOFF2 dello stesso font, per utilizzo locale sul web.
- `OFL.txt`: licenza SIL Open Font License 1.1 originale, da conservare con il font.

Il wordmark usa `wght=600`. I file SVG a tracciati non richiedono il caricamento del font.

Fonte: <https://github.com/google/fonts/tree/main/ofl/sora>

Download del TTF: <https://raw.githubusercontent.com/google/fonts/main/ofl/sora/Sora%5Bwght%5D.ttf>

Acquisito il 15 novembre 2026. Le impronte dei file sono nel manifesto del kit.
